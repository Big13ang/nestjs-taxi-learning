Guards: the bouncer of your APIGuardها: نگهبان درِ API تو

A Guard answers one yes/no question before a route runs: is this request allowed in? If it returns false, Nest stops everything and replies 403 — the controller never even hears about it.Guard قبل از اجرا شدن یک Route به یک سوال بله/خیر جواب می‌دهد: آیا این Request اجازه ورود دارد؟ اگر false برگرداند، Nest همه چیز را متوقف می‌کند و جواب 403 می‌دهد — Controller اصلاً خبردار نمی‌شود.

SAMPLE · Concept · Auth · 5 minنمونه · مفهوم · احراز هویت · ۵ دقیقه

Mental modelمدل ذهنی

Think of a club. The middleware is the street camera — it sees everyone passing. The Guard is the bouncer at the door — it checks your ID and decides. The controller is the party inside — it only meets people who got in.یک کلاب را تصور کن. Middleware دوربین خیابان است — همه رهگذرها را می‌بیند. Guard نگهبان دم در است — کارت شناسایی‌ات را چک می‌کند و تصمیم می‌گیرد. Controller مهمانی داخل است — فقط کسانی را می‌بیند که وارد شده‌اند.

Key ideaایده کلیدیGuards run after middleware and before interceptors, pipes and the controller. They have access to the route's metadata — so they can behave differently per route.Guardها بعد از Middleware و قبل از Interceptorها، Pipeها و Controller اجرا می‌شوند. به Metadata آن Route دسترسی دارند — پس می‌توانند برای هر Route رفتار متفاوتی داشته باشند.

Simple exampleمثال ساده

Only admins may delete a driver. Instead of checking the role inside every controller, write it once as a Guard:فقط Adminها می‌توانند یک راننده را حذف کنند. به جای چک کردن Role داخل تک‌تک Controllerها، آن را یک بار به‌صورت Guard بنویس:

@Injectable()
export class AdminGuard implements CanActivate {
  canActivate(ctx: ExecutionContext): boolean {
    const req = ctx.switchToHttp().getRequest();
    return req.user?.role === 'ADMIN';   // true = in, false = 403
  }
}

@Delete(':id')
@UseGuards(AdminGuard)   // ← bouncer posted at this door
removeDriver(@Param('id') id: string) { /* only admins reach this */ }
See it happenدر عمل ببین

A driver sends DELETE /drivers/7 → Guard reads role: 'DRIVER' → returns false → 403 Forbidden. The removeDriver method never runs. An admin sends the same request → true → driver deleted.یک راننده DELETE /drivers/7 می‌فرستد ← Guard مقدار role: 'DRIVER' را می‌خواند ← false برمی‌گرداند ← 403 Forbidden. متد removeDriver اصلاً اجرا نمی‌شود. یک Admin همان Request را می‌فرستد ← true ← راننده حذف می‌شود.

Common mistakeاشتباه رایج

Watch outحواست باشدDoing role checks inside controllers (if (user.role !== 'ADMIN') throw… copy-pasted everywhere). One forgotten check = one open door. Guards exist so the check lives in exactly one place.چک کردن Role داخل Controllerها (if (user.role !== 'ADMIN') throw… که همه جا Copy-Paste شده). یک چک فراموش‌شده = یک درِ باز. Guardها برای این هستند که چک فقط در یک جا زندگی کند.
